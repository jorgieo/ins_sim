# Bibliography

Works cited in these pages. Equation and section numbers quoted from
Groves always refer to the **second edition (2013)**; the first edition
(2008) numbers its equations differently.

These docs follow Groves' *notation*. Every derivation, figure and table
here is written fresh, and none is reproduced from the book.

## Inertial navigation

**Groves (2013)** { #groves2013 }
:   P. D. Groves, *Principles of GNSS, Inertial, and Multisensor Integrated
    Navigation Systems*, 2nd ed. Boston, MA: Artech House, 2013. The source
    of the notation used throughout these docs.

**Titterton & Weston (2004)** { #titterton2004 }
:   D. H. Titterton and J. L. Weston, *Strapdown Inertial Navigation
    Technology*, 2nd ed. Stevenage, UK: IET, 2004.

**Savage (1998a)** { #savage1998a }
:   P. G. Savage, "Strapdown inertial navigation integration algorithm
    design, part 1: Attitude algorithms," *Journal of Guidance, Control, and
    Dynamics*, vol. 21, no. 1, pp. 19–28, 1998.

**Savage (1998b)** { #savage1998b }
:   P. G. Savage, "Strapdown inertial navigation integration algorithm
    design, part 2: Velocity and position algorithms," *Journal of
    Guidance, Control, and Dynamics*, vol. 21, no. 2, pp. 208–221, 1998.

## Earth model

**NGA (2014)** { #nga2014 }
:   National Geospatial-Intelligence Agency, *Department of Defense World
    Geodetic System 1984: Its Definition and Relationships with Local
    Geodetic Systems*, NGA.STND.0036_1.0.0_WGS84, 2014.

## Inertial sensor errors

**IEEE Std 952** { #ieee952 }
:   *IEEE Standard Specification Format Guide and Test Procedure for
    Single-Axis Interferometric Fiber Optic Gyros*, IEEE Std 952-1997.
    Defines angle random walk and bias instability through the Allan
    variance.

**El-Sheimy et al. (2008)** { #elsheimy2008 }
:   N. El-Sheimy, H. Hou, and X. Niu, "Analysis and modeling of inertial
    sensors using Allan variance," *IEEE Transactions on Instrumentation and
    Measurement*, vol. 57, no. 1, pp. 140–149, 2008.
