    Sensors¶

    The IMU error model: the datasheet parameters and the noisy gyro and accelerometer outputs they produce.

    ins_sim.sensors.imu ¶

    IMU error model: datasheet parameters and simulated gyro and accelerometer outputs.

    An IMUSpec, usually loaded from YAML with load_imu_spec, sets the spread of each error term in the Groves (2013) sensor model:

    meas_f_ib_b     = b_a + (I + M_a)·f_ib_b     + w_a
meas_omega_ib_b = b_g + (I + M_g)·omega_ib_b + w_g

    generate_imu_samples draws one realization of these errors along a truth trajectory, and draw_initial_misalignment draws the initial alignment error. The model is explained on the IMU error model theory page, and its symbols on Notation & conventions.

    GM_ALLAN_PEAK module-attribute ¶

    GM_ALLAN_PEAK = 0.6173642831

    Peak of the Allan deviation of a first-order Gauss-Markov process, per unit of its spread.

    The peak occurs at an averaging time of 1.8926 correlation times. ins_sim models bias instability with such a process and sets its steady-state spread σ = B / GM_ALLAN_PEAK, so that the simulated bias's Allan deviation peaks at the datasheet bias instability B.

    IMUSpec dataclass ¶

    IMUSpec(gyro_arw: float = 0.002 * pi / 180 / 60, gyro_bias_instability: float = 0.01 * pi / 180 / 3600, gyro_bias_tau: float = 3600.0, gyro_br_std: float = 0.01 * pi / 180 / 3600, gyro_sf_std: float = 0.0, gyro_ma_std: float = 0.0, accel_vrw: float = 0.005 / 60, accel_bias_instability: float = 5e-06 * 9.80665, accel_bias_tau: float = 3600.0, accel_br_std: float = 2.5e-05 * 9.80665, accel_sf_std: float = 0.0, accel_ma_std: float = 0.0, align_tilt_std: float = 0.0, align_heading_std: float = 0.0)

    Navigation-grade IMU error parameters, as quoted on a sensor datasheet.

    The defaults are typical of fielded navigation-grade systems, such as a ring-laser-gyro aircraft INS:

    Parameter Gyro Accelerometer
    Random walk (ARW, VRW) 0.002 °/√h 0.005 m/s/√h
    Bias instability 0.01 °/h 5 µg
    Turn-on repeatability 0.01 °/h 25 µg

    Every field is a datasheet parameter in SI units; each one sets the spread of a Groves (2013) error term (see the Notation & conventions page). Bias instability is the datasheet value, the floor of the sensor's Allan deviation. The in-run bias is simulated as a first-order Gauss-Markov process whose steady-state spread (gyro_gm_std, accel_gm_std) is chosen so that its Allan deviation peaks at exactly that value.

    Attributes:

    • gyro_arw (float) –

      Gyro angular random walk, the density of the white noise w_g [rad/√s].

    • gyro_bias_instability (float) –

      Gyro bias instability from the datasheet, the floor of the Allan deviation [rad/s]. Sets the dynamic bias b_gd.

    • gyro_bias_tau (float) –

      Correlation time of the Gauss-Markov process that models the gyro bias instability [s].

    • gyro_br_std (float) –

      Gyro turn-on bias repeatability, the std dev of the static bias b_gs [rad/s].

    • gyro_sf_std (float) –

      Gyro scale-factor error std dev (diagonal of M_g), drawn once per run per axis [dimensionless, e.g. 5e-6 = 5 ppm].

    • gyro_ma_std (float) –

      Gyro axis-misalignment std dev (off-diagonal of M_g), drawn once per run per element [rad].

    • accel_vrw (float) –

      Accelerometer velocity random walk, the density of the white noise w_a [(m/s)/√s].

    • accel_bias_instability (float) –

      Accelerometer bias instability from the datasheet, the floor of the Allan deviation [m/s²]. Sets the dynamic bias b_ad.

    • accel_bias_tau (float) –

      Correlation time of the Gauss-Markov process that models the accelerometer bias instability [s].

    • accel_br_std (float) –

      Accelerometer turn-on bias repeatability, the std dev of the static bias b_as [m/s²].

    • accel_sf_std (float) –

      Accelerometer scale-factor error std dev (diagonal of M_a) [dimensionless].

    • accel_ma_std (float) –

      Accelerometer axis-misalignment std dev (off-diagonal of M_a) [rad].

    • align_tilt_std (float) –

      Initial-alignment tilt (N/E) error std dev [rad]. Physically ≈ accel repeatability / g.

    • align_heading_std (float) –

      Initial-alignment heading (azimuth) error std dev [rad]. Physically ≈ gyrocompass limit, gyro repeatability / (omega_ie·cos L_b).

    Note

    The multiplicative (scale factor, misalignment) and initial-alignment terms default to zero — they apply only when specified — so zero-noise diagnostic specs and legacy YAMLs keep their exact-passthrough behavior.

    gyro_gm_std property ¶

    gyro_gm_std: float

    Steady-state std dev of the gyro Gauss-Markov bias b_gd [rad/s].

    Chosen so that the bias's Allan deviation peaks at gyro_bias_instability: σ = B / GM_ALLAN_PEAK ≈ 1.62·B.

    accel_gm_std property ¶

    accel_gm_std: float

    Steady-state std dev of the accelerometer Gauss-Markov bias b_ad [m/s²].

    Chosen so that the bias's Allan deviation peaks at accel_bias_instability: σ = B / GM_ALLAN_PEAK ≈ 1.62·B.

    IMUSamples ¶

    Bases: NamedTuple

    Simulated IMU outputs, one row per sample interval tau_i.

    Attributes:

    • meas_omega_ib_b (ndarray) –

      Gyro output, the measured angular rate of the body relative to inertial space, resolved in body axes, shape (M, 3) [rad/s].

    • meas_f_ib_b (ndarray) –

      Accelerometer output, the measured specific force, resolved in body axes, shape (M, 3) [m/s²].

    def load_imu_spec(yaml_path: str) -> IMUSpec:
    """Loads an IMUSpec from a YAML file expressed in datasheet units.

    Args:
        yaml_path: Path to a YAML file with `gyro` and `accel` sections
            in datasheet units (deg/√hr, deg/hr, µg, etc.).

    Returns:
        IMUSpec: Equivalent error-parameter set converted to SI units.

    Examples:
        >>> import numpy as np
        >>> from ins_sim.config import default_imu_spec_path
        >>> from ins_sim.sensors.imu import load_imu_spec
        >>> spec = load_imu_spec(str(default_imu_spec_path()))
        >>> round(float(np.rad2deg(spec.gyro_arw) * 60), 4)   # back to °/√h
        0.002
    """
    with open(yaml_path) as fh:
        cfg = yaml.safe_load(fh)
    g = cfg["gyro"]
    a = cfg["accel"]
    al = cfg.get("alignment", {})
    # --8<-- [start:datasheet_units]
    DEG_HR = np.pi / 180 / 3600
    return IMUSpec(
        gyro_arw     = g["arw_deg_per_rt_hr"]          * np.pi / 180 / 60,
        gyro_bias_instability = g["bias_instab_deg_per_hr"]  * DEG_HR,
        gyro_bias_tau         = g["bias_tau_s"],
        gyro_br_std  = g["repeatability_deg_per_hr"]   * DEG_HR,
        gyro_sf_std  = g.get("scale_factor_ppm", 0.0)   * 1e-6,
        gyro_ma_std  = g.get("misalignment_urad", 0.0)  * 1e-6,
        accel_vrw    = a["vrw_m_per_s_per_rt_hr"]      / 60,
        accel_bias_instability = a["bias_instab_ug"]     * 1e-6 * 9.80665,
        accel_bias_tau         = a["bias_tau_s"],
        accel_br_std = a["repeatability_ug"]            * 1e-6 * 9.80665,
        accel_sf_std = a.get("scale_factor_ppm", 0.0)   * 1e-6,
        accel_ma_std = a.get("misalignment_urad", 0.0)  * 1e-6,
        align_tilt_std    = al.get("tilt_std_deg", 0.0)    * np.pi / 180,
        align_heading_std = al.get("heading_std_deg", 0.0) * np.pi / 180,
    )

    draw_initial_misalignment ¶

    draw_initial_misalignment(spec: IMUSpec, rng: Generator) -> ndarray

    Draws a per-run initial-alignment attitude error delta_psi_nb^n.

    Models the residual error of a stationary gyrocompass alignment: small tilts about North/East (limited by accelerometer bias over g) and a larger azimuth error about Down (limited by east-gyro bias over omega_ie·cos L_b). Apply as C_b^n(estimated) = exp([delta_psi_nb^n ^])·C_b^n(true).

    Parameters:

    • spec (IMUSpec) –

      IMU error-parameter set (align_tilt_std, align_heading_std).

    • rng (Generator) –

      Seeded NumPy random generator.

    Returns:

    • ndarray –

      numpy.ndarray: Attitude error rotation vector resolved in NED, [North tilt, East tilt, Down (heading)], shape (3,) [rad].

    Examples:

    >>> import numpy as np
>>> from ins_sim.sensors.imu import IMUSpec, draw_initial_misalignment
>>> spec = IMUSpec(align_tilt_std=1e-5, align_heading_std=7e-4)
>>> draw_initial_misalignment(spec, np.random.default_rng(0)).shape
(3,)

    def draw_initial_misalignment(spec: IMUSpec,
                              rng: np.random.Generator) -> np.ndarray:
    """Draws a per-run initial-alignment attitude error delta_psi_nb^n.

    Models the residual error of a stationary gyrocompass alignment:
    small tilts about North/East (limited by accelerometer bias over g)
    and a larger azimuth error about Down (limited by east-gyro bias
    over omega_ie·cos L_b). Apply as C_b^n(estimated) =
    exp([delta_psi_nb^n ^])·C_b^n(true).

    Args:
        spec: IMU error-parameter set (align_tilt_std,
            align_heading_std).
        rng: Seeded NumPy random generator.

    Returns:
        numpy.ndarray: Attitude error rotation vector resolved in NED,
            [North tilt, East tilt, Down (heading)], shape (3,) [rad].

    Examples:
        >>> import numpy as np
        >>> from ins_sim.sensors.imu import IMUSpec, draw_initial_misalignment
        >>> spec = IMUSpec(align_tilt_std=1e-5, align_heading_std=7e-4)
        >>> draw_initial_misalignment(spec, np.random.default_rng(0)).shape
        (3,)
    """
    # --8<-- [start:initial_misalignment]
    return rng.normal(0.0, [spec.align_tilt_std,
                            spec.align_tilt_std,
                            spec.align_heading_std])

    generate_imu_samples ¶

    generate_imu_samples(truth: TruthTrajectory, spec: IMUSpec, rng: Generator) -> IMUSamples

    Generates noisy IMU samples from a truth trajectory and an error spec.

    Per-axis IMU model (Groves notation):

    meas_f_ib_b     = b_a + (I + M_a)·f_ib_b     + w_a
meas_omega_ib_b = b_g + (I + M_g)·omega_ib_b + w_g
    • M_a, M_g: scale factor (diagonal) and misalignment (off-diagonal), drawn once per run.
    • b_as, b_gs: static (turn-on) bias ~ N(0, σ_BR²), drawn once per run.
    • b_ad, b_gd: dynamic bias, a first-order Gauss-Markov process with correlation time τ and steady-state spread σ = B / GM_ALLAN_PEAK, so that its Allan deviation peaks at the datasheet bias instability B. Stationary from t = 0.
    • w_a, w_g: white noise, with σ = VRW/√tau_i or ARW/√tau_i per sample.

    The gyro and accelerometer triads draw from separate random streams spawned from rng, so changing one triad's parameters leaves the other's error realization unchanged.

    Parameters:

    • truth (TruthTrajectory) –

      Truth trajectory exposing t, tau_i, omega_ib_b (shape (M, 3) [rad/s]) and f_ib_b (shape (M, 3) [m/s²]).

    • spec (IMUSpec) –

      IMU error-parameter set.

    • rng (Generator) –

      Seeded NumPy random generator. Two child streams are spawned from it, one per sensor triad.

    Returns:

    • IMUSamples ( IMUSamples ) –

      (meas_omega_ib_b, meas_f_ib_b), the noisy gyro and accelerometer outputs, each shape (M, 3).

    Examples:

    >>> import numpy as np
>>> from ins_sim.sensors.imu import IMUSpec, generate_imu_samples
>>> from ins_sim.trajectory.kinematics import TruthTrajectory
>>> from ins_sim.trajectory.spline import NEDSplinePath
>>> path = NEDSplinePath([[0.0, 0.0, 0.0], [1000.0, 0.0, 0.0]])
>>> truth = TruthTrajectory.from_spline(path, speed=100.0, tau_i=0.1)
>>> imu = generate_imu_samples(truth, IMUSpec(), np.random.default_rng(1))
>>> imu.meas_omega_ib_b.shape == truth.omega_ib_b.shape
True

    def generate_imu_samples(truth: "TruthTrajectory", spec: IMUSpec,
                         rng: np.random.Generator) -> IMUSamples:
    """Generates noisy IMU samples from a truth trajectory and an error spec.

    Per-axis IMU model (Groves notation):

        meas_f_ib_b     = b_a + (I + M_a)·f_ib_b     + w_a
        meas_omega_ib_b = b_g + (I + M_g)·omega_ib_b + w_g

    - M_a, M_g: scale factor (diagonal) and misalignment (off-diagonal),
      drawn once per run.
    - b_as, b_gs: static (turn-on) bias ~ N(0, σ_BR²), drawn once per run.
    - b_ad, b_gd: dynamic bias, a first-order Gauss-Markov process with
      correlation time τ and steady-state spread σ = B / GM_ALLAN_PEAK, so
      that its Allan deviation peaks at the datasheet bias instability B.
      Stationary from t = 0.
    - w_a, w_g: white noise, with σ = VRW/√tau_i or ARW/√tau_i per sample.

    The gyro and accelerometer triads draw from separate random streams
    spawned from `rng`, so changing one triad's parameters leaves the
    other's error realization unchanged.

    Args:
        truth: Truth trajectory exposing `t`, `tau_i`, `omega_ib_b`
            (shape (M, 3) [rad/s]) and `f_ib_b` (shape (M, 3) [m/s²]).
        spec: IMU error-parameter set.
        rng: Seeded NumPy random generator. Two child streams are spawned
            from it, one per sensor triad.

    Returns:
        IMUSamples: (meas_omega_ib_b, meas_f_ib_b), the noisy gyro and
            accelerometer outputs, each shape (M, 3).

    Examples:
        >>> import numpy as np
        >>> from ins_sim.sensors.imu import IMUSpec, generate_imu_samples
        >>> from ins_sim.trajectory.kinematics import TruthTrajectory
        >>> from ins_sim.trajectory.spline import NEDSplinePath
        >>> path = NEDSplinePath([[0.0, 0.0, 0.0], [1000.0, 0.0, 0.0]])
        >>> truth = TruthTrajectory.from_spline(path, speed=100.0, tau_i=0.1)
        >>> imu = generate_imu_samples(truth, IMUSpec(), np.random.default_rng(1))
        >>> imu.meas_omega_ib_b.shape == truth.omega_ib_b.shape
        True
    """
    tau_i = truth.tau_i
    rng_gyro, rng_accel = rng.spawn(2)
    meas_omega_ib_b = _triad_measurement(
        rng_gyro, truth.omega_ib_b, tau_i, spec.gyro_sf_std, spec.gyro_ma_std,
        spec.gyro_br_std, spec.gyro_gm_std, spec.gyro_bias_tau, spec.gyro_arw)
    meas_f_ib_b = _triad_measurement(
        rng_accel, truth.f_ib_b, tau_i, spec.accel_sf_std, spec.accel_ma_std,
        spec.accel_br_std, spec.accel_gm_std, spec.accel_bias_tau, spec.accel_vrw)
    return IMUSamples(meas_omega_ib_b, meas_f_ib_b)
